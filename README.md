# FPL Stats Dashboard

A single-file dashboard for Fantasy Premier League player leaderboards, weekly consistency, player comparison, and match results. Data is pulled live from the official FPL API on each page load.

## Features
- Leaderboards (Total Points, Form, Value, Ownership, ICT, Goals + Assists)
- "3+ Every Week" and "All Player" weekly breakdown tables with fixtures
- Player comparison with position + club filters
- Match results with events, bonus points, and a full-player-list popup on mobile
- Club filter, reset, and light/dark theme
- Responsive layout for mobile

## Local preview
Open `index.html` directly in a browser, or serve the folder:

```
npx serve .
```

## Deploy
Hosted as a static site on Vercel. `index.html` is served at the root automatically.
